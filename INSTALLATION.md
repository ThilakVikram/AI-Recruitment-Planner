# Installation Guide

This document explains how to install, configure, and run the Recruiter AI Co-Pilot project locally.

## 1. Prerequisites

Install the following software before starting.

### Required

* Node.js `>= 20.9`
* npm
* MySQL `8.x`
* Git

Check the installed versions:

```bash
node --version
npm --version
mysql --version
git --version
```

The project has been tested with Node.js 24 and MySQL 8.

---

# 2. Clone the Repository

Clone the project:

```bash
git clone <repository-url>
```

Go into the project directory:

```bash
cd recruiter-ai
```

---

# 3. Install Dependencies

Install the Node.js dependencies:

```bash
npm install
```

---

# 4. Create MySQL Database

Login to MySQL:

```bash
mysql -u root -p
```

Create the application databases:

```sql
CREATE DATABASE recruiter_ai;
CREATE DATABASE recruiter_ai_shadow;
```

Create the application user:

```sql
CREATE USER 'recruiter_ai'@'localhost' IDENTIFIED BY 'your_password';
```

Grant permissions:

```sql
GRANT ALL PRIVILEGES ON recruiter_ai.* TO 'recruiter_ai'@'localhost';

GRANT ALL PRIVILEGES ON recruiter_ai_shadow.* TO 'recruiter_ai'@'localhost';

FLUSH PRIVILEGES;
```

Exit MySQL:

```sql
EXIT;
```

---

# 5. Configure Environment Variables

Create the environment file:

```bash
cp .env.example .env
```

Update `.env` with your local configuration.

Example:

```env
DATABASE_URL="mysql://recruiter_ai:your_password@localhost:3306/recruiter_ai"

SHADOW_DATABASE_URL="mysql://recruiter_ai:your_password@localhost:3306/recruiter_ai_shadow"

BETTER_AUTH_SECRET="your-long-random-secret"

BETTER_AUTH_URL="http://localhost:3000"

ANTHROPIC_API_KEY="your-anthropic-api-key"

ANTHROPIC_MODEL="your-anthropic-model"

NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

## Environment Variables

| Variable              | Purpose                              |
| --------------------- | ------------------------------------ |
| `DATABASE_URL`        | MySQL database connection            |
| `SHADOW_DATABASE_URL` | Prisma development shadow database   |
| `BETTER_AUTH_SECRET`  | Secret used by Better Auth           |
| `BETTER_AUTH_URL`     | Application URL used by Better Auth  |
| `ANTHROPIC_API_KEY`   | Anthropic API key                    |
| `ANTHROPIC_MODEL`     | Claude model used by the application |
| `NEXT_PUBLIC_APP_URL` | Public application URL               |

Do not commit `.env` to Git.

---

# 6. Generate Prisma Client

Generate the Prisma client:

```bash
npm run db:generate
```

---

# 7. Run Database Migrations

Apply the database migrations:

```bash
npm run db:migrate
```

This creates the required tables in the `recruiter_ai` database.

---

# 8. Seed Initial Users

Run the seed script:

```bash
npm run db:seed
```

The seed script creates four recruiter accounts by default:

```text
recruiter1@company.com
recruiter2@company.com
recruiter3@company.com
recruiter4@company.com
```

Temporary passwords are generated by the seed script and printed in the terminal.

Save these passwords securely.

The users are created with:

```text
mustChangePassword = true
```

Therefore, each user must change their temporary password after the first login.

### Custom Users

Users can be customized using:

```env
SEED_USERS="user1@company.com,user2@company.com,user3@company.com"
```

Then run:

```bash
npm run db:seed
```

Existing users are not reset by the seed script.

---

# 9. Start Development Server

Start the Next.js development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

Open the URL in your browser.

---

# 10. First Login

Use one of the accounts created by the seed script.

Example:

```text
Email:
recruiter1@company.com

Password:
<temporary password printed by the seed script>
```

After login, the user will be redirected to the password-change page.

Set a new password.

After changing the password, the recruiter can access the application.

After starting the application, verify the following:

* Recruiter can log in.

* Dashboard loads after changing the password.

# 15. Common Issues

## MySQL Access Denied

If you see:

```text
Access denied for user
```

Check:

```env
DATABASE_URL="mysql://recruiter_ai:password@localhost:3306/recruiter_ai"
```

Also verify the MySQL user permissions:

```sql
SHOW GRANTS FOR 'recruiter_ai'@'localhost';
```

---

## Prisma Cannot Connect to MySQL

Check that MySQL is running.

Linux:

```bash
sudo systemctl status mysql
```

Start it if required:

```bash
sudo systemctl start mysql
```

Test the connection:

```bash
mysql -u recruiter_ai -p -h localhost recruiter_ai
```

---

## Prisma Shadow Database Error

If Prisma reports an error related to the shadow database, verify that the user has permission on:

```text
recruiter_ai
recruiter_ai_shadow
```

Check:

```sql
SHOW GRANTS FOR 'recruiter_ai'@'localhost';
```

---

## Anthropic API Error

Verify:

```env
ANTHROPIC_API_KEY="your-api-key"
ANTHROPIC_MODEL="your-model"
```

Then restart the development server:

```bash
npm run dev
```

For a production process managed by PM2:

```bash
pm2 restart recruiter-ai --update-env
```

---

## Port 3000 Already in Use

Check which process is using port 3000.

Linux:

```bash
sudo lsof -i :3000
```

You can also start Next.js on another port:

```bash
npm run dev -- -p 3001
```

---

# 16. Database Reset During Development

If the local database needs to be completely recreated during development, use Prisma carefully.

```bash
npx prisma migrate reset
```

This deletes the database data and recreates it.

Then seed the users again:

```bash
npm run db:seed
```

**Do not use `prisma migrate reset` on a production database.**
